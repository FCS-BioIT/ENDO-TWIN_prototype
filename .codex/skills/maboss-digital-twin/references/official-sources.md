# Official and primary MaBoSS sources

Check current local versions and documentation before using version-sensitive
commands.

- MaBoSS project: https://maboss.curie.fr/
- MaBoSS source organization: https://github.com/sysbio-curie
- PyMaBoSS: https://github.com/colomoto/pyMaBoSS
- PyMaBoSS documentation: https://pymaboss.readthedocs.io/
- Stoll et al., continuous-time Boolean modeling:
  https://doi.org/10.1186/1752-0509-6-116
- MaBoSS modeling review and extensions:
  https://doi.org/10.3389/fmolb.2022.1071177
- Reproducible CoLoMoTo logical-model tutorial:
  https://doi.org/10.1371/journal.pcbi.1012441

These sources support the formalism and APIs. They do not validate an ADOC
network, personalization rule, or clinical claim.
