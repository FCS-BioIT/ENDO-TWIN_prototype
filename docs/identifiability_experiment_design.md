# Identifiability-driven experimental design: one perturbation, one panel

Status: **analysis only, for owner review.** No model, observation map, admission
table, declaration, ledger row, evidence-register row or intervention-library
row was created or changed. Stage 4b and Stage 4c are not reopened; the Stage 4c
refusal record stands and no defect in it was found. Nothing here is
pre-registered: §9 lists what would have to be, and that act is the owner's.

The question: **given one wet-lab perturbation experiment, which perturbation
and which readouts most reduce ambiguity in the digital twin?** Not which
intervention is easiest to admit, which gives the biggest predicted phenotype,
or which unblocks Stage 4d most cheaply.

Every number below is regenerated by

```bash
pixi run identifiability-design          # write the tables
pixi run identifiability-design-check    # fail if any is stale
```

into `docs/identifiability_design/` — `alias_pairs.tsv`, `readout_value.tsv`,
`perturbation_readout_matrix.tsv`, `minimal_identifying_panel.tsv`,
`panel_structural_value.tsv`, `variant_arm_discrimination.tsv` and
`design_yield.tsv`. **Every number in this document comes from one of those
seven tables**, or from a committed artefact cited where it is used.

Use the pixi tasks, not a bare `python -m`: the generator reads the registered
Gate-3 variants, whose module pulls in PyYAML, so an ambient interpreter without
the locked environment cannot produce these tables. It now fails loudly rather
than quietly emitting a variant-free table, which is why the task is the
documented entry point. The generator reuses the committed `veto_expressivity`
parser and marginal computation, and reproduces
`docs/stage4b/v060_veto_expressivity.tsv` exactly as a side effect.
It is outside `IMPLEMENTATION_GLOBS`: it produces no simulation result.

> **The distinction this document is built on, and which earlier revisions of it
> violated twice.** `experiments.variant_discrimination` states it: *"structural
> distinguishability is not experimental distinguishability."* §4 reports what
> enlarging `O` would make **resolvable**; §5 reports what a named design,
> in a stated condition and latent scenario, actually **resolves**. They are
> different tables and must never be added together.
>
> Three rules follow, and §5 applies all three. An alias pair is resolved only
> when the design runs **both** of its vetoes, because the pair is a claim about
> two interventions. Nothing is unioned over conditions or latent scenarios.
> And a controlled input counts as "current design" only against its
> **registered default**, never against `off`.

## 1. The current identifiability problem

### 1.1 What the classes are

`OUT_STABLE_ADHESION` is reached through two serial conjunctions
(`E_RECEPTIVE_SURFACE`, `OUT_MATERNAL_ADHESION_COMPETENCE`). So the whole of
class A1 is **five independent single-points-of-failure for adhesion, each
predicted to drive it from 0.82 to exactly 0.00** in
`adhesion_challenge_hormone_treated`: `E_GP130_STAT3` and `E_LIF` (the
receptive-surface conjunct), `E_PC6` (via `E_DAG1_FULL := not E_PC6`),
`S_HAND2` (via `S_FGF_MITOGENIC` and `E_ESTROGENIC_PROLIFERATION`, a
cross-compartment route) and `S_TAZ_ECM` (via `X_MECHANICAL_PERMISSIVE_ECM`).

A2 (`E_ITGAVB3_5`, `X_SPP1_LUMEN_FREE`) differs in kind: both remove only
`X_ADHESION_ROUTE_SPP1`, leaving the redundant route, so both give −0.42 and
neither has any other consequence.

### 1.2 The taxonomy, derived rather than asserted

`alias_pairs.tsv` assigns each of the 48 same-class pairs a reason.

| Brief's category | Derived label | Meaning | Fixable by measurement? |
|---|---|---|---|
| 2. coupled by topology | `rule_identical_everywhere` | no node separates the pair in any context or scenario | **No.** Only a rule change |
| 2′. coupled, weaker | `separable_only_at_targets` | the only separating nodes are the vetoed nodes themselves | Only by measuring engagement — identifies the **agent**, not the mechanism |
| 1. `O` too small | `separable_downstream` | separating nodes exist that neither veto targets | **Yes** |
| 4. structurally null | the 9-member `null` class | the veto changes no observed node anywhere | Only by enlarging `O` |

Two "aliases" in the committed artefact are **not** ambiguities and are excluded
before pairs are formed: `hand2_loss`/`S_HAND2` and
`anti_spp1`/`X_SPP1_LUMEN_FREE` are the same veto reached two ways. A1 therefore
has **five** distinct targets, not six; A2 has two, not three.

### 1.3 Two facts that change what the experiment is for

**(a) The `E_GP130_STAT3` / `E_LIF` alias is a known model defect.** The pair is
`separable_only_at_targets` — the committed rule is the bare chain
`E_GP130_STAT3 := E_LIF`, so vetoing LIF zeroes pSTAT3 too and the only
separating node is `E_LIF` itself. The repository already holds primary human
causal evidence that the rule is false. `context/evidence-register.tsv`,
LIT-IL11-001 (REF-072, Marwood 2009, full text verified 2026-09-16):

> a second GP130-family ligand acts in human endometrial epithelium, so
> `E_GP130_STAT3 = E_LIF` is false

and, sharper:

> the ligands dissociate DOWNSTREAM of both STAT3 and ITGA2 … A convergent-only
> motif is therefore NECESSARY BUT NOT SUFFICIENT: it predicts
> interchangeability, which this refutes.

So a repair is **available on existing evidence**, independently of any
experiment. Whether to make it, and whether to sequence it ahead of further
admission work, is an owner decision and is not asserted here. What *is* already
recorded is narrower and separate: Stage 4c §7 requires "a recorded model-reading
decision about the level at which `E_LIF` stands for LIF" before anti-LIF could
be admitted — a statement about the entity **level**, not about this rule.

The consequence for this unit is only that the shot should not be spent
re-deriving a result the register already holds.

**(b) The missing intermediates are named.** The dissociation runs through
**ITGA2**; the second ligand is **IL-11**. `config/node_entity_map.tsv` carries
both as explicit `model_gap` rows for v0.6.0 — `IL11@expression`,
`IL11@extracellular`, `ITGA2@activity`, `ITGB1@activity`, staged as `X_IL11` and
`E_ITGA2B1`. The category-3 ambiguity is registered, not speculative.

## 5. Experimental yield, for a stated condition and scenario

`design_yield.tsv`. Two rules, both of which earlier revisions of this analysis
broke and independent review caught.

**An alias pair needs both of its vetoes run.** An alias pair is a claim that two
*interventions* are observationally equivalent. Refuting it experimentally means
observing both signatures. Running one arm and comparing the result against the
model's prediction for the other substitutes a prediction for the observation it
is supposed to be tested against. That is reported below as variant
discrimination — which is what it is — and never as alias resolution.

**Nothing is unioned over conditions or scenarios.** Yield is reported for the
condition the design states (`adhesion_challenge_hormone_treated`) and for each
declared latent scenario separately. `E_KLF12_HIGH` is hand-set, and
`docs/scrna/klf12_prior_finding.md` records that **no measured prior for it could
be established** — so both of its values are carried, never averaged or silently
fixed.

| Design | Veto arms run | New assay classes | Alias pairs resolved | **Distinct** registered variants discriminated, no extra arm |
|---|---|---:|---:|---:|
| | | | low / high KLF12 | low / high |
| 1 readout-only, existing arms | none | 0 | 0 / 0 | 0 / 1 |
| 2 PC6 + panel D | `E_PC6` | 2 | 0 / 0 | 0 / 2 |
| **3 HAND2 + panel B** | `S_HAND2` | **0** | 0 / 0 | **1 / 2** |
| 3b HAND2 + panel E | `S_HAND2` | 3 | 0 / 0 | 1 / 3 |
| 4 STAT3 + panel C | `E_GP130_STAT3` | 1 | 0 / 0 | 1 / 2 |
| 5 LIF + panel C | `E_LIF` | 1 | 0 / 0 | 1 / 2 |
| 6 two-arm STAT3 **and** LIF + panel C | both | 1 | **1** / 0 | 1 / 2 |

The variant column counts **distinct `variant_id`s**. An earlier revision counted
`variant@arm` labels, so a variant seen under two arms counted twice and every
multi-arm design was inflated — Design 6 read 2 where it discriminates one
variant under two arms. The detail column in `design_yield.tsv` groups the arms
under each variant so the count and the detail cannot drift apart again.

### 5.1 The headline, and it is a negative one

> **No single-perturbation design resolves any alias pair.** One shot cannot
> de-alias two interventions, because de-aliasing is a claim about both of them
> and one arm observes one. Only the two-arm design resolves a pair — one pair,
> only when `E_KLF12_HIGH` is low, and only at engagement level (§7): its one
> separating node is a veto target, not a downstream consequence.

What a one-shot experiment *can* do is **discriminate competing registered rule
variants under the arm it runs**. That is the quantity the last column measures,
and it is what the ranking in §7 is built on. It is also exactly what the
repository's own Gate-3 machinery (`experiments.variant_discrimination`) was
built to do, which is corroboration rather than coincidence.

### 5.2 What carries each discrimination

Under the executed condition with KLF12 low, and with input settings the current
design already uses:

| Variant | Arm that exposes it | Readout that carries it | New assay class? |
|---|---|---|---|
| `hand2_required_decidual_variant` | `veto:S_HAND2` | **`S_IGFBP1` and `S_PRL` — already in `O`** | **no** |
| `CD98-c` | `veto:E_GP130_STAT3` or `veto:E_LIF` | `E_CD98_CD9` | yes |
| `CDH1-b` | any arm, including unperturbed | `E_CDH1_APICAL` | yes |

`CDH1-b` is discriminated without any perturbation at all, so it is a readout
question, not an experiment question.

### 5.3 Registered variants, one arm and one scenario at a time

`variant_arm_discrimination.tsv` covers **seven Gate-3 variants registered
against v0.4.0 and mechanically transported to v0.6.0 under exact baseline-rule
identity, plus the non-default variants registered directly in this model's own
`rule_variants.tsv`** — under every arm, every
controlled-input setting and **both** latent scenarios. Three points it settles:

> Under `GP130-b` (`E_GP130_STAT3 := E_LIF or X_IL11`) with IL-11 supplied, a
> **LIF veto** differs from the committed model in all ten contexts while a
> **STAT3 veto produces no differing row at all**. The two arms are not
> interchangeable, and any claim of the form "a STAT3 or LIF veto predicts X" is
> false for one of them. IL-11 is not in any current medium, so this needs a
> second arm and is reported in the extra-arm column.

> `literature_parity_v020` (`E_LIF := E_SECRETORY_STATE`, the pre-KLF12 rule) is
> discriminable **only when `E_KLF12_HIGH` is high** — which is why fixing the
> scenario at one value hid it entirely.

> `PC6-b` requires `E_DAG1_CLEAVABLE = off`, and that is the *intervention*, not
> the status quo: `INPUT_DEFAULTS` registers the endogenous substrate as
> cleavable. It is an extra-arm item, not a within-design one.

**Transport is guarded, and fails closed.** The Gate-3 tuple is registered
against v0.4.0 while this analysis evaluates v0.6.0. A variant asserts "the
committed rule, versus this alternative", so it may only be carried across where
the committed rule it departs from is *the same rule* in both models. The
generator parses both networks and requires exact equality of the baseline rule
for every overridden node — currently `E_CD98_CD9`, `E_CDH1_APICAL`,
`E_GP130_STAT3`, `E_DAG1_CLEAVED` and `E_DAG1_FULL`, all five of which are
identical between the two versions — and **refuses** rather than adjusting if any
differs. A test pins the invariant.

**No variant was invented to score it.** In particular the IL-11 → ANXA2
executor is **not** reconstructed:
`deep_research_adhesion_model_2026-09-11.candidate-node-dispositions.tsv`
refuses to write it because doing so "would invent the functional link, which
GP130-b's own limitation column already forbids", and EDGE-007 is registered at
confidence 4 with "No direct LIF-to-ANXA2 proof in this inventory". An earlier
revision of this document scored exactly that unwritten variant.

## 6. The STAT3 question, answered directly

1. **"Measure pSTAT3 to prove the inhibitor works" is engagement and adds no
   expressivity class.** Stage 4c's finding stands, and §3 sharpens it: pSTAT3
   cannot even separate `E_GP130_STAT3` from `E_LIF`.
2. **"Perturb STAT3 and measure a designed panel" is better, but not by much,
   and not in the way one would hope.** A STAT3 arm resolves **no** alias pair.
   It discriminates one registered variant, `CD98-c`, and only by adding surface
   CD98/CD9 — a new assay class.
3. **The STAT3 and LIF arms are not interchangeable** (§5.3), and neither is the
   best use of one shot. A bath-applied STAT3 agent additionally engages stromal
   `S_STAT3`, a §3.5.1 floor entity, so its result carries
   `compound_claim_blocked` and cannot be attributed to the named agent — an
   interpretation cost, not merely a paperwork one.

So the answer to the question as posed is **no**: coupling a STAT3 perturbation
to a designed panel does not make it worth the one shot. It buys one variant at
the price of a new assay class, where a stromal arm buys one variant at no assay
cost at all.

**One constraint on any LIF arm.** The entity map reads `E_LIF` as
`LIF@expression`. A *neutralising antibody* does not change expression, so it
does not realise this veto — the structural ground on which Stage 4c refused
anti-LIF. A LIF arm therefore needs a perturbation acting at **expression
level** — knockdown, knockout, silencing or transcriptional repression are all
admissible in principle; what is excluded is a reagent that removes the ligand
extracellularly without changing its expression. "Knockdown" below is shorthand
for that class, not a requirement that it be RNAi specifically.

## 7. Top three designs

**Design 3 — HAND2 knockdown, panel B.** It attains the same distinct-variant
yield as the one-assay-class designs — 1 under KLF12-low, 2 under KLF12-high,
identical to Designs 4, 5 and 6 — at **zero new assay classes**, so it dominates
them *on that one cost variable* at equal yield. **New assay classes are the
only cost this analysis scores.** Stromal knockdown is a new *manipulation*
class whose feasibility and cost on the ADOC chip are unknown and unscored
(§8), so "cheaper overall" is not a claim these tables can support, and the
recommendation below is conditional on **both** — on stromal knockdown being
feasible on the chip at all, and on its cost not exceeding that of the
pharmacological arms it is preferred over. Neither is scored here, and a
comparative manipulation cost could reverse the preference without changing a
single number in the tables. Its discrimination,
`hand2_required_decidual_variant` (whether HAND2 is required for
decidualisation), is carried by `S_PRL` and `S_IGFBP1`, which the platform
already measures by existing ELISA. **Both discriminating measurements are
stromal**, so this is not an epithelial-vs-stromal readout: it perturbs the
stroma and reads the stroma. (The epithelial readout
`E_ESTROGENIC_PROLIFERATION` belongs to Design 3b and is not what discriminates
the variant.) It is CAND-09 in the repository's own register.

*Weaknesses, stated against the table rather than around it.* It resolves no
alias pair — nothing single-arm does. Its yield is **not** independent of the
latent: it rises from 1 to 2 when `E_KLF12_HIGH` is high, as every design's does,
and the second variant there (`literature_parity_v020`) is one that Design 1
picks up for free. The human evidence for HAND2 is correlative, REF-028 being
mouse PR-Cre, and stromal knockdown on chip is a new manipulation class even
though it is not a new assay class.

**Design 6 — STAT3 and LIF knockdown as two arms, panel C.** The only design
that resolves an alias pair at all, and it does so **at engagement level, not
mechanistically**: the single separating node is `E_LIF`, the target of one of
the two arms, so the pair is `separable_only_at_targets` and §1.2 classes that
as identifying the *agent* rather than the mechanism. It resolves exactly one
pair
(`E_GP130_STAT3`|`E_LIF`), only under KLF12-low. It discriminates one distinct variant (`CD98-c`, under both of its arms).
*Weakness:* it is two perturbations, so it does not fit a one-shot budget — it
is listed to make the price of de-aliasing visible rather than implied — and
even that price buys only engagement-level separation, as above.

**Design 4 or 5 — STAT3 inhibition or LIF knockdown, panel C.** One distinct
variant (`CD98-c`) for one new assay class. *Weakness:* on assay-class cost it
is dominated by Design 3, which reaches the same distinct-variant count in both
scenarios for none. That comparison holds only on assay classes: a
pharmacological arm may well be easier to run than a stromal knockdown, and
nothing here scores that.

## 7b. Perturbations not included in the quantitative design ranking

`DESIGNS` holds **seven** named designs. For the one-shot question they are not
interchangeable: **five are single-perturbation designs** (`2_pc6_veto`,
`3_hand2_veto`, `3b_hand2_veto_with_proliferation`, `4_stat3_veto`,
`5_lif_veto`), **Design 1 is the readout-only comparator** running no new veto,
and **Design 6 is the two-perturbation comparator**, included to price genuine
de-aliasing rather than as a one-shot option. So the one-shot field is five
designs, over four distinct veto targets — `E_PC6`, `S_HAND2`,
`E_GP130_STAT3`, `E_LIF`.

The model admits **19 eligible direct targets**, so the named designs are a
chosen subset and **in no sense exhaust the representable perturbation
universe**. Fifteen eligible targets are **not enumerated in the named
`design_yield` designs**; this section discusses four of them plus one candidate
that is not an eligible target at all, and it does not claim to cover the
remainder.

Three kinds of case are at work among the five, and they are kept apart because
only the first is rankable:

1. **anti-SPP1 and TAZ** — faithfully representable, omitted from the named
   designs. An omission on my part, not a judgement, so their yield is computed
   below (§7b.1).
2. **integrin and ANXA2** — an idealised node veto exists, but it does not
   faithfully encode a concrete biological perturbation, so the real experiment
   is **unrankable** pending TI-03 or a node-reading decision (§7b.1b).
3. **BMP** — excluded from the eligible veto universe altogether, because
   `S_BMP2` conflates BMP2 expression with BMP pathway activity (§7b.2).

Nothing below changes a number. Each row's "what it would discriminate" is read
from the committed `variant_arm_discrimination.tsv` at the executed context
(`adhesion_challenge_hormone_treated`), `E_KLF12_HIGH = low`, current-design
input settings — the same slice §5 ranks on.

### 7b.1 Two faithfully representable candidates, omitted from the named designs

**anti-SPP1 → `X_SPP1_LUMEN_FREE`** and **TAZ inhibition → `S_TAZ_ECM`** are
faithfully representable: `SPP1@extracellular` and `WWTR1@activity`, both
`single`, and in each case a real agent acts at the node's declared level. They
are absent from `design_yield.tsv` because I did not enumerate them, not because
anything rules them out.

Their yield is therefore computable, and it is zero. Read at the executed
context from `variant_arm_discrimination.tsv`:

| Scenario | What `veto:X_SPP1_LUMEN_FREE` and `veto:S_TAZ_ECM` expose | What `unperturbed_arms` already exposes |
|---|---|---|
| `E_KLF12_HIGH = low` | `CDH1-b` | `CDH1-b` |
| `E_KLF12_HIGH = high` | `CD98-c`, `CDH1-b`, `literature_parity_v020` | `CD98-c`, `CDH1-b`, `literature_parity_v020` |

Identical to the unperturbed arms in both scenarios, so **their incremental,
perturbation-attributable registered-variant yield is zero under both values of
`E_KLF12_HIGH`.** Two caveats on that zero: it is a statement about *these
readouts* — `CD98-c` and `CDH1-b` need `E_CD98_CD9` or `E_CDH1_APICAL`, new
assay classes, before anything is observable at all — and about *registered
variants*, so an arm may still be worth running for evidence no registered
variant encodes.

One supported distinction between the two: **anti-SPP1 is the only one of the
four candidates in this section that already carries a committed
intervention-library `activity_veto` row** (`anti_spp1` on
`X_SPP1_LUMEN_FREE`). Nothing follows from that about what TAZ would require.

### 7b.1b Two candidates whose node veto does not encode a real perturbation

**integrin blockade → `E_ITGAVB3_5`** and **ANXA2 perturbation →
`E_ANXA2_ACTIN`** are different in kind. An idealised veto of each node exists
in the generated tables, but **it does not faithfully encode any concrete
biological perturbation**, so it cannot be used to rank the real experiment.

- `E_ITGAVB3_5` is `ambiguous` over `ITGAV`, `ITGB3` and `ITGB5`. Anti-β3 leaves
  αvβ5 intact while anti-αv disables both; one node cannot represent that
  difference, so "veto the node" corresponds to no reagent. It is unapprovable
  until **TI-03** by owner decision 7, and TI-03 records that the node reduces
  to exactly `E_SECRETORY_STATE`, so a split buys nothing without a second
  determinant.
- `E_ANXA2_ACTIN` is `ambiguous` over `ANXA2`, `RHOA` and
  `process:f_actin_architecture` — a cytoskeletal state rather than a target.
  It is refused by default under §11.2, and it is additionally a **structural
  null on `O`**.

**Both are therefore unrankable** — pending TI-03 for the integrin node and a
recorded node-reading decision for ANXA2. Their idealised veto rows in
`variant_arm_discrimination.tsv` and `alias_pairs.tsv` are reported **only as
model diagnostics**, and it would be an error to read them as evidence about the
corresponding wet-lab perturbations. An earlier revision of this section did
exactly that: it quoted their computed variant yield to argue they could not
dominate, after stating in the same paragraph that they are not faithfully
representable. That inference is withdrawn.

What these candidates would still be worth, independently of Stage 4b and of the
ranking: a TAZ or ANXA2 arm would supply the first direct evidence on nodes the
repository currently carries on a single mechanistic literature line. That claim
needs no admission and is not scored here.

### 7b.2 BMP receptor or pathway inhibition — not in the executable veto universe

**`S_BMP2` is not an eligible direct target and a BMP-receptor inhibitor must
not be translated into `veto:S_BMP2`.** This is mechanical, not a judgement of
mine. The O8b audit records `S_BMP2` with `model_role = regulator_or_readout`
and `policy = refused`, and `config/direct_effect_target_policy.tsv` gives the
reason verbatim:

> `S_BMP2`. The dictionary leaves it ambiguous, and DTR007 separates BMP2
> abundance from BMP pathway activity, which this one node conflates.

The entity map carries the conflation in the open: two rows for the same node,
`BMP2@expression` and `BMP2@activity`, both `ambiguous`. A receptor or SMAD
inhibitor acts on **pathway activity** and leaves ligand abundance untouched, so
mapping it onto a node that stands for both would assert an engagement the agent
does not have — the same move Stage 4c refused. `S_BMP2` is accordingly absent
from `v060_veto_expressivity.tsv` altogether, which is why no BMP arm appears in
any table here.

**Could resolving that ambiguity plausibly outrank the recommended design?**
**It is not currently quantitatively rankable**, and that is the finding — not
that it would rank low. It cannot enter the scored set until a model split is
pre-registered, because until then there is no node a BMP-pathway agent could
legitimately address.

**What the v0.6 rules themselves say**, derived here rather than carried over.
The committed network has

```
S_BMP2         := (S_PGR and S_PKA) or S_NR2F2
S_DECIDUALIZED := S_PGR and S_PKA and S_BMP2
S_PRL          := S_DECIDUALIZED
S_IGFBP1       := S_DECIDUALIZED
```

so `S_BMP2` is a conjunct of `S_DECIDUALIZED`, and the only registered stromal
variant keeps it as one (`hand2_required_decidual_variant` is
`S_PGR and S_PKA and S_BMP2 and S_HAND2`). Clamping `S_BMP2` off therefore
abolishes `S_DECIDUALIZED`, and with it `S_PRL` and `S_IGFBP1`, **identically
under the committed rule and under that variant**. On v0.6 rules a BMP-pathway
clamp read on PRL and IGFBP-1 would confirm a shared conjunct rather than choose
between the two rules — which is exactly the discrimination Design 3 does make.

*`docs/stage3_experiment_selection.md` reached the same conclusion — "BMP
receptor inhibition separates nothing … It confirms a rule rather than choosing
between rules" — but that was computed on v0.4 and is cited here as **historical
corroboration**, not as proof about v0.6. The statement above stands on the v0.6
rules quoted.*

Note also what a BMP clamp is *not*: `S_HAND2 := S_BMP2 or S_PGR`, so with
progestin present `S_HAND2` stays on. A BMP arm is not a backdoor HAND2 arm.

**After a split its yield is unwritten, not low.** Whether a pathway-activity
veto would discriminate anything depends on rules the split has not yet written,
and a design whose yield is unwritten cannot be ranked against one whose yield is
computed — in either direction. Two things keep the question live: a BMP arm
would read out on `S_PRL` and `S_IGFBP1`, the same zero-new-assay-class readouts
as Design 3, so if the de-conflated rules made a pathway veto discriminate a
registered variant it would land in the same cost bracket; and the conflation is
a live defect independently of any experiment, since DTR007 separates abundance
from activity and the node does not. Fixing it is a model-reading decision worth
taking on its own merits, and this analysis is not the unit that should take it.

## 8. If there is truly only one shot

**Recommendation, scoped: Design 3 — HAND2 knockdown, reading PRL and IGFBP-1 on
the existing outlet ELISAs, with panel B carried for context — is the best of
the five single-perturbation designs this analysis quantitatively scores.** That
is the whole of the claim. The other two named designs are comparators, not
rivals: Design 1 runs no new veto, and Design 6 is two perturbations. It is
**not** a claim about the best representable experiment, and not a claim about
the best conceivable one: the five cover four of the model's nineteen eligible
direct targets (§7b).

Three boundaries, all from §7b. **anti-SPP1 and TAZ** are faithfully
representable and cannot dominate: their perturbation-attributable yield is
**zero in both latent scenarios**, because everything they expose is already
exposed by the unperturbed arms. **Integrin and ANXA2** are *unrankable* rather
than beaten — their node vetoes do not encode a real perturbation, so no
comparison with them is available pending TI-03 or a node-reading decision. And
a **BMP-pathway** experiment is not quantitatively rankable until a model split
is pre-registered. The eleven remaining eligible targets are unexamined.

The recommendation is further conditional on stromal knockdown being feasible on
the ADOC chip, and on its cost being comparable to or lower than a
pharmacological arm. Both conditions are unscored by this analysis (§7). If
stromal knockdown turns out infeasible, or materially more expensive than a
STAT3 or LIF arm, then Design 4 or 5 is preferred instead at the price of one
new assay class, and nothing in the tables needs to change for that to follow.

It reaches the same distinct-variant yield as every one-assay-class design, in
both latent scenarios, for no new assay capability — so on the one cost variable
scored here it is the cheapest design that returns anything, not the only one
that does, and not necessarily the cheapest to run.

**What it would and would not establish.** A HAND2 arm discriminates the
committed rule from the registered `hand2_required_decidual_variant` — a
*conditional choice between two model variants*, conditional on the knockdown
having actually worked. It does **not** establish that HAND2 is biologically
required for decidualisation. An incomplete or ineffective knockdown and a
genuine absence of necessity produce the identical negative observation, and
this design cannot tell them apart: `S_HAND2` is `HAND2@activity`, a transcript
measurement is not an activity measurement, so engagement here is
`phenotype_only` — the same ground on which Stage 4c refused its candidate
(§8.1). A necessity claim would additionally require verified manipulation, an
activity-level engagement measure, and a positive control; none of those is in
this design, and the human evidence for HAND2 is correlative in any case
(REF-028 is mouse PR-Cre). **A negative result is therefore the one most open
to misreading, and must not be reported as "HAND2 is not required".**

Two claims an earlier revision made here were false against the table and are
withdrawn: that Design 3 was the *only* design with a non-zero yield at zero new
assay classes (Design 1 also costs nothing and discriminates
`literature_parity_v020` under KLF12-high), and that its return does not depend
on the latent (it moves from 1 to 2 distinct variants). Nothing in this
recommendation rests on either.

**This is the third recommendation this analysis has produced, and the first two
were wrong for reasons worth recording.** The first counted structural
resolvability as experimental yield and recommended a readout-only design. The
second counted an alias pair as resolved when only one of its two interventions
was run, and recommended a STAT3 or LIF arm. Both were caught by independent
review, and both inflated what one perturbation can deliver. The corrected
arithmetic says one perturbation de-aliases nothing, which is why the
recommendation is now the cheapest informative arm rather than the one with the
largest apparent yield.

**Three contingencies the owner can settle and I could not:**

1. Whether stromal knockdown is feasible on the ADOC chip at all. If not,
   Design 3 falls and the question becomes which new assay class is cheapest.
2. Whether ADOC can run scRNA-seq on a perturbed arm, and at what cost. Panel B
   assumes it can; the recommendation's core (PRL, IGFBP-1) does not.
3. Whether a two-arm experiment is affordable. If it is, Design 6 is the only
   route to de-aliasing anything, and the question changes shape.

### 8.2 What the adhesion endpoint can and cannot support

**No power claim is made here, and an earlier revision's was wrong.** It read
the recorded counts — 0/12 untreated, 9/19 HT, 1/8 HT+mifepristone
(SOFIA-ADH-001–003) — as binomial over independent embryos, and concluded that
0/19 would exclude anything above about 18% and so separate abolition from
partial loss. That treats the embryo as the independent unit, which the
repository explicitly says it is not.

`docs/gate3_scope_adjudication.md` records the HT arm as **9 chips across 4
donors**, with the per-embryo assignment "referenced but absent" —
`SOFIA-ADH-001` says it "must be recovered if available" and it never was. With
no embryo-to-chip mapping, the clustering cannot be estimated, the effective
sample size is unknown and is smaller than the embryo count, and the same
document sets the claim ceiling on adhesion as **ordinal and aggregate**. So no
interval, exclusion bound or power statement is available at the unit the data
are recorded at, and none is asserted.

Two consequences for this unit. Any design resting on a *graded* adhesion
comparison is unsupportable, not merely underpowered — and every adhesion delta
in `docs/stage4b/v060_veto_expressivity.tsv` is a relay prior, so every
magnitude prediction is direction-only regardless. And the recommended design
deliberately does not rest on adhesion at all: its result is carried by two
secreted analytes with established ELISAs, which is among the stronger reasons
to prefer it. A quantitative adhesion claim would first need a preregistered
allocation at the chip or donor level, which is an experimental-design decision
outside this analysis.

## 9. What must be pre-registered first

1. **Observation-map rows** for each added node — adding to `O` changes the
   expressivity classes and therefore the Stage 4b §5.6 arithmetic.
2. **A leakage rule**, per the KLF12 precedent
   (`docs/scrna/klf12_prior_preregistration.md`): the same cells must not both
   set a prior and score a prediction. That precedent also shows a criterion can
   fire on stateless simulated data, so any threshold needs the same null
   calibration.
3. **A level decision for free SPP1**:
   `docs/c2_observation_compartments/attribution_report.md` prohibits attributing
   an outlet SPP1 concentration to epithelial or stromal expression without
   compartment-resolved evidence — which the scRNA half supplies, which is why
   the two belong in one panel.
4. **A decision on `E_GP130_STAT3 := E_LIF`** (§1.3a) — if the owner elects to
   repair it, as its own act rather than inside an admission. Listed because the
   chosen design's interpretation depends on which rule is current, not as a
   precondition this analysis imposes.
5. **No threshold, topology or mapping tuned on the same outcomes used to
   validate**, per `AGENTS.md`.

assay class.

## 11. Stage 4d

**Stage 4d should stay blocked, and this analysis does not change why.** Its gate
is the §5.6 two-approval condition, there are zero approvals, and nothing here
creates one. The Stage 4c correction holds: approvals in A1 and A2 would satisfy
§5.6 with no model change, so observable structure is not the binding constraint.

What this unit adds is a reason not to optimise for unblocking 4d. Panel B or C
would change the expressivity classes §5.6 counts over, so running the chosen
design first means later approvals are adjudicated against a less degenerate
class structure. That is a prioritisation, recorded as the owner's to make.
