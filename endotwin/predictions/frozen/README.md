# Frozen prediction records

Each subdirectory is an immutable record written by `pixi run endotwin-freeze`
(`src/endotwin/predictions.py`): the spec, a byte copy of the model, protocols,
interventions and observation map, the predictions with their sensitivity
analysis, provenance, and `MANIFEST.sha256`.
